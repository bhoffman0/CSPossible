    Section 3.1 Lists

    135 minutes
    Quick Links: 3.1.1, 3.1.2, 3.1.3, 3.1.4, 3.1.5, 3.1.6, 3.1.7, 3.1.8, 3.1.9, 3.1.10, 3.1.11, 3.1.12, 3.1.13, 3.1.14
    🔗
    We use lists every day to keep track of things, for example, shopping lists, to-do lists, or song playlists. Python makes it easy to work with lists. In this topic, we will learn to use lists to store values, manipulate list contents, and traverse lists with loops.
    🔗

    Subsection 3.1.1 Lists as Data Collections

    Essential Knowledge 3.1.1. 3.1.A.1.

    A data collection is a way to store multiple related values together so a program can treat them as one unit, such as storing multiple names, scores, or messages. Different programming languages support different kinds of collections, such as lists, arrays, or dictionaries.
    🔗
    🔗

    Essential Knowledge 3.1.2. 3.1.A.2.

    Data collections help programs support user-facing features that involve many items, such as a list of saved favorites, recent searches, or a playlist. Storing related values in one variable makes it easier to manage, update, and process the information as users interact with an app.
    🔗
    🔗
    All programming languages have ways to store collections of data. Python has a built-in data type called a list which can store an ordered sequence of items. Lists are sometimes called arrays in other programming languages.
    🔗
    You can imagine a list as a row of lockers where each locker holds one item or element. The lockers are numbered with an index that starts at 0 for the first locker, 1 for the second locker, and so on.
    🔗

    Essential Knowledge 3.1.3. 3.1.A.3.

    A value stored inside a data collection is an element. Programs can work with the entire collection of items as one unit or with individual elements.
    🔗
    🔗

    Essential Knowledge 3.1.4. 3.1.A.4.

    In a list, elements are stored in an ordered sequence, meaning the position of each element matters (first, second, third, etc.). When the following code runs, a list called aList contains the elements v1, v2, v3, and so on.
    🔗
    aList = [v1, v2, v3, ...]
    🔗
    Here are some examples of lists in Python. Notice how square brackers [] are used to collect multiple values to store in one list variable. Instead of using many variables like score1, score2, etc., which would get unmanageable pretty quickly, you can use a single list variable like scores or shopping_list to store a collection of values.
    🔗
    # A shopping list
shopping_list = ["milk", "eggs", "bread", "butter"]
# A list of scores
scores = [95, 87, 92, 100]
    🔗

    Subsection 3.1.2 Index to Access Elements

    Essential Knowledge 3.1.5. 3.1.A.7.

    An index is a number used to reference a specific element by position in a list or in a string. Many programming languages use zero-based indexing, meaning the first element is at index 0, the second at index 1, and so on.
    🔗
    🔗
    To access elements in a list, we use the list name and the index (the position or number) of the element in square brackets. For example, shopping_list[0] accesses the first element in the shopping_list, which is "milk". Most programming languages, including Python, use zero-based indexing where the first item in the list is at index 0. Just like binary code, computers almost always start counting at 0.
    🔗
    Note that the AP CSP exam currently starts indexing at 1 in its pseudocode including in the 2027 exam, but will switch to zero-based indexing as of 2028.
    🔗

    Essential Knowledge 3.1.6. 3.1.A.8.

    Programs can access a specific list element using its index. This allows programs to read or use stored values in a list. When the following code runs, the element in aList at index j is accessed.
    🔗
    aList[j]
    🔗

    Essential Knowledge 3.1.7. 3.1.A.9.

    Lists support apps that respond to users by remembering and reusing information. For example, a music app can store a user’s queued songs in a list. Each time the user taps "Add to Queue," the song title is appended to the list, and the app uses the list to display the upcoming songs in order and play the next track.
    🔗
    🔗
    Imagine a Python list called lockers. Let’s put your books in locker 0 and a backpack in locker 1 with the code below. To get to a specific locker or a specific element in a list, use the list name followed by square brackets and the index (number) of the element you want to access like below.
    🔗
    lockers[0] = "books"
lockers[1] = "backpack"
print("What's in locker 0?", lockers[0] )
print("What's in locker 1?", lockers[1] )

    In groups or as a class, simulate a list using students in chairs. Organize a line of empty chairs as the list in memory. Each student who sits in a chair represents a value in the list. The first chair in the line of chairs has the index 0. The second chair has the index 1, and so on. Have students follow the code similar to the example below. Substitute in the names of students in your class. For example, chairs[0] = "Pat" means that the student in chair 0 gets up and Pat sits down.     Subsection 3.1.4 Changing List Elements with Assignment

    Essential Knowledge 3.1.8. 3.1.B.2.

    Elements in a list can be changed to different values, which allows a program to update stored information without rebuilding the entire list. When the following code runs, the value of x is assigned to the element at index j in aList. The previous value at that index is overwritten, and the length of the list does not change.
    🔗
    aList[j] = x

    Essential Knowledge 3.1.9. 3.1.B.1.

    Programmers sometimes make a copy of a list so they can modify the copy, such as removing or reordering elements, while keeping the original list unchanged. Preserving the original list can make a program easier to understand, test, and debug because the program can still refer back to the original data if needed. When the following code runs, a copy of the list bList is assigned to the list aList.
    🔗
    aList = bList
    🔗
    Before making changes to a list, it’s often a good idea to make a copy of it first. Then the original list can be preserved and used later if needed. The [index] notation can be used to access and change elements in a list.
    🔗
    # A list of scores
scores = [95, 87, 92, 100]
# Make a copy of the scores list
scores_bonus = scores
# Add bonus points to the first two scores in the copy
scores_bonus[0] += 5
scores_bonus[1] += 5
    🔗

    Subsection 3.1.5 Length of a List, Random Elements, and Slicing

    Essential Knowledge 3.1.10. 3.1.B.3.

    The length of a list can change while a program runs as elements are added or removed. Knowing the length of a list helps programmers write code that works correctly as the list changes. When the following code runs, it evaluates to the number of items in aList.
    🔗
    length(aList)
    🔗
    In Python, you can get the length of a list by using the len(aList) function, note the shortened form of len for length. In AP Pseudocode, the function used is length(aList).
    🔗
    # A list of names
names = ["Jordan", "Alex", "Sam", "Taylor"]
# Get the length of the names list
print("The length of the names list is:", len(names))

    Essential Knowledge 3.1.11. 3.1.B.6.

    To select a random element from a list, a program can generate a random index and use it to access an element. This allows for features like selecting a random song from a playlist, choosing a random prompt in a game, or assigning a random partner from a list of names. In programming languages that use zero-based indexing, if aList has length(aList) items, the valid indices are 0 through length(aList) - 1. When the following code runs, the program generates one of the valid indices with equal likelihood and accesses the element at that index.
    🔗
    aList[random(0, length(aList) - 1)]
    🔗
    Sometimes you may want to pick a random element from the list. One way to do this is to generate a random index. It would start at 0 and go up to the length of the list minus 1. If there are 3 elements in the list, the valid indices would be 0, 1, and 2. In Python, you can use the random.randint() function to generate a random index. The valid indices are 0 through len(list) - 1. For example, if you have a list of songs, you can select a random song from the playlist using the code random.randint(0, len(songs) - 1). Python actually has a built-in function called random.choice(list) that will select a random element from a list, but we will use the random index method here to match AP pseudocode.
    🔗
    import random
songs = ["Song 1", "Song 2", "Song 3", "Song 4"]
random_index = random.randint(0, len(songs) - 1)
random_song = songs[random_index]
print(random_song)

    Subsection 3.1.6 Appending to Lists

    Essential Knowledge 3.1.12. 3.1.A.5.

    Lists can start empty, which allows a program to collect information, such as items a user adds, results found during a search, or responses entered in a form. When the following code runs, an empty list is assigned to aList.
    🔗
    aList = [ ]
    🔗
    If you do not know what values you want to store in a list when you create it, you can start with empty list ([]) which is a list that contains no elements and add in elements while the program is running. For example, we can start with an empty shopping list.
    🔗
    # An empty shopping list
shopping_list = []

    Essential Knowledge 3.1.13. 3.1.A.6.

    Lists can be built over time by adding new elements, often as the user enters information or the program collects it. When the following code runs, value is added to the end of aList and the length of aList is increased by 1.
    🔗
    aList.append(value)
    🔗
    Elements can be added to a list using the append function which adds the element to the end of the list.
    🔗
    # An empty shopping list
shopping_list = []
shopping_list.append("milk")
shopping_list.append("eggs")
shopping_list.append("bread")
print(shopping_list)

    Subsection 3.1.7 Insert and Remove List Elements

    Essential Knowledge 3.1.14. 3.1.B.4.

    Elements can be inserted at particular positions in a list, which allows a program to keep items in a meaningful order, such as priority or ranking, as new information is added. When the following code runs, any elements at indices greater than or equal to j are shifted so that their indices are increased by 1 and value is placed at index j. The length of the list is increased by 1.
    🔗
    aList.insert(j, value)
    🔗

    Essential Knowledge 3.1.15. 3.1.B.5.

    Elements at particular positions can be removed from a list, which allows a program to delete outdated, incorrect, or unwanted information while keeping the remaining elements usable.     Subsection 3.1.8 Traversing Lists with Loops

    Essential Knowledge 3.1.19. 3.1.C.3.

    Iteration statements can be used to traverse a list, which allows a program to process each element in order without writing repeated code for every element. When the following code runs, the variable item is assigned the value of each element of aList sequentially, in order, from the first element to the last element. The code in block of statements is executed once for each element in aList.
    🔗
    for item in aList
{
   <block of statements>
}
    🔗
    Python has a simple way to traverse (step through) a list, visiting each element in the list, using a for loop with the pattern: for item in list:
    🔗
    aList = [1, 2, 3, 4, 5]
for item in aList:
    print(item)

    Activity 3.1.15.

    🔗
    An index-controlled for-loop using range(len(aList)) or a while loop can also be used to traverse a list. The loop variable is the index to access each element in the list. This is why programmers often use the variable i, short for index, as the loop variable. However, it is a lot more complex. If you do not need the index, it is simpler to use the for item in list loop instead. The code below compares all three loops. The first one is the simplest and most often used with lists.
    🔗
    aList = [1, 2, 3, 4, 5]
# Simple for loop for lists
for item in aList:
    print(item)

# More complex indexed for-loop
for i in range(len(aList)):
    print( aList[i] )

# More complex while loop
i = 0
while i < len(aList):
    print( aList[i] )
    i += 1

    Subsection 3.1.11 Data Abstraction with Lists

    In previous lessons, we talked about abstraction in computer science which is about focusing on the general features while hiding the specific details. Data Abstraction is the process of hiding the complex implementation details of a data structure and showing only the needed features to the user. Variables are a type of data abstraction because they allow programmers to use a name to represent a value without needing to know how the value is stored in memory. Lists are another type of data abstraction because they allow programmers to use a single variable name to represent a collection of values without needing to know how the values are stored or organized in memory. Data abstraction using lists reduces complexity in code and makes it easier to read, write, and maintain.
    🔗

    Essential Knowledge 3.1.26. 3.1.D.1.

    Data Abstraction manages complexity by allowing programmers to use data based on its name and purpose without needing to focus on how the data is represented. This separation helps programmers reason about what the data represents and what operations can be done with it.
    🔗
    🔗

    Essential Knowledge 3.1.27. 3.1.D.2.

    A list is a type of data abstraction because it allows many related values to be treated as a single variable. Instead of writing code for many individual variables, programmers can use the list’s name to perform the same kinds of operations on its elements, such as accessing, updating, inserting, removing, or traversing.
    🔗
    🔗

    Data abstraction reduces complexity by reducing duplication in code. For example, using a single list and a loop can process any number of elements, instead of requiring many separate variables and repeated statements.
