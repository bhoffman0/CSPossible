    Section 1.7 Mathematical Expressions

    90 minutes
    🔗

    Subsection 1.7.1 Learning Objectives

    Learning Objective 1.7.1. 1.7.A.

    Develop code using mathematical expressions, and determine the result of these expressions.
    🔗
    🔗

    Learning Objective 1.7.2. 1.7.B.

    Develop code to generate random numbers, and determine the possible values that could be produced as a result.
    🔗
    🔗
    🔗

    Subsection 1.7.2 Mathematical Expressions

    Essential Knowledge 1.7.3. 1.7.A.1.

    Apps use mathematical expressions to calculate values that help users make decisions, such as prices, time estimates, or progress toward a goal.
    🔗
    🔗

    Essential Knowledge 1.7.4. 1.7.A.2.

    Mathematical expressions can be used to update the state of a program by changing values stored in variables, such as scores, timers, levels, and resource usage.
    🔗
    🔗

    Essential Knowledge 1.7.5. 1.7.A.3.

    An integer is a numeric data type that represents positive and negative whole numbers, including zero. Integers are often used for counts or scores in a program.
    🔗
    🔗

    Essential Knowledge 1.7.6. 1.7.A.4.

    Arithmetic operators appear in most programming languages, but the notation used for those operations is determined by the language. Common arithmetic operators include addition +, subtraction -, multiplication *, division / and modulo %.
    🔗
    🔗

    Essential Knowledge 1.7.7. 1.7.A.5.

    The modulo operation % evaluates to the remainder when one integer is divided by another: a % b is the remainder when a is divided by b. Modulo can be used to identify patterns in numbers, such as whether a number is even or odd, and to help format values in user-friendly ways, such as converting total minutes into hours and minutes.
    🔗
    🔗

    Essential Knowledge 1.7.8. 1.7.A.6.

    Expressions enclosed in parentheses are evaluated first. Then, multiplication *, division /, and modulo % operations are evaluated from left to right. Then, addition + and subtraction - operations are evaluated from left to right.
    🔗
    🔗

    Essential Knowledge 1.7.9. 1.7.A.7.

    The result of a mathematical expression can be determined by evaluating it step by step using the order of operations and operators.
    🔗
    🔗

    Essential Knowledge 1.7.10. 1.7.A.8.

    Mathematical expressions can include variables. To determine the result, substitute the current values of variables and then evaluate the expression using the order of operations.
    🔗
    🔗
    🔗

    Subsection 1.7.3 Random Numbers

    Essential Knowledge 1.7.11. 1.7.B.1.

    Apps use random number generation to create variety and unpredictability, such as in games, simulations, or randomly generated prompts.
    🔗
    🔗

    Essential Knowledge 1.7.12. 1.7.B.2.

    Random values can support variation in app behavior, such as shuffling a playlist, selecting a random item, or assigning outcomes like rolling a die.
    🔗
    🔗

    Essential Knowledge 1.7.13. 1.7.B.3.

    Programmers can determine the set of possible values produced by a random command by identifying the endpoints and whether they are included. When the following code runs, a random integer from a to b, including a and b, is generated and returned. Each result is equally likely to occur. The possible results of random(a, b) are all integers from a through b. random(a, b)
    🔗
    🔗

    Essential Knowledge 1.7.14. 1.7.B.4.

    When a program uses random number generation, the same code can produce different results each time it runs.
