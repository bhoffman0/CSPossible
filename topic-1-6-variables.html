    Section 1.6 Variables

    90 minutes
    🔗

    Subsection 1.6.1 Learning Objectives

    Learning Objective 1.6.1. 1.6.A.

    Identify the use of variables in an app while interacting with it.
    🔗
    🔗

    Learning Objective 1.6.2. 1.6.B.

    Develop code for assignment statements using variables, and determine the values that are stored in the variables as a result.
    🔗
    🔗

    Learning Objective 1.6.3. 1.6.C.

    Develop code to store and modify strings, and determine the output produced.
    🔗
    🔗
    🔗

    Subsection 1.6.2 Identifying Variables in Apps

    Essential Knowledge 1.6.4. 1.6.A.1.

    A variable is a named storage location used to hold a value that can change while the program is running. It is an abstraction that lets programmers use a name to represent a value.
    🔗
    🔗

    Essential Knowledge 1.6.5. 1.6.A.2.

    Apps use variables to keep track of changing information by updating their values as the user interacts with the app. Programs can then use a variable’s current value to decide what to do next and what feedback to provide, such as updating the screen, playing a sound, or triggering a vibration.
    🔗
    🔗

    Essential Knowledge 1.6.6. 1.6.A.3.

    Every value in a program has a data type, such as a number, Boolean, or string. Some programming languages require programmers to specify the type, while others determine it automatically by how the data is used.
    🔗
    🔗

    Essential Knowledge 1.6.7. 1.6.A.4.

    The choice of data type depends on what a value represents. Values used to count or measure are best represented as numbers, values that record a true or false condition are best represented as Booleans, and values that store text are best represented as strings. The data type affects what operations can be performed on the variable and how accurately the output is represented in an app.
    🔗
    🔗

    Essential Knowledge 1.6.8. 1.6.A.5.

    Variables are often used to store information about the user or a program’s state, such as a username, a selected theme, a score, progress toward a goal, a shopping cart total, or whether notifications are on. The program can use the stored value to adjust its behavior or display the value to the user.
    🔗
    🔗

    Essential Knowledge 1.6.9. 1.6.A.6.

    Program state is the set of values and information a program is storing at a specific moment, including variable values and any inputs it is using. As the program runs, the state changes when inputs are received and variables are updated.
    🔗
    🔗

    Essential Knowledge 1.6.10. 1.6.A.7.

    Users can infer the use of variables in an app by observing information that changes over time, such as counters, totals, settings, progress, or status, and reasoning about what values the app must store and update to produce those changes.
    🔗
    🔗
    🔗

    Subsection 1.6.3 Variables and Assignment

    Essential Knowledge 1.6.11. 1.6.B.1.

    The assignment operator allows a program to initialize or change the value stored in a variable. When the following code runs, expression is evaluated, and the resulting value is stored in the variable a. a = expression
    🔗
    🔗

    Essential Knowledge 1.6.12. 1.6.B.2.

    Variables are initialized by assigning an initial value before they are used. After initialization, later statements can use the variable’s value and update it as the program runs.
    🔗
    🔗

    Essential Knowledge 1.6.13. 1.6.B.3.

    Using meaningful variable names improves readability and helps programmers understand what the stored values represent.
    🔗
    🔗

    Essential Knowledge 1.6.14. 1.6.B.4.

    A variable stores its most recently assigned value.
    🔗
    🔗

    Essential Knowledge 1.6.15. 1.6.B.5.

    The value stored in a variable after a sequence of assignment statements can be determined by tracing statements in order and updating the variable’s value after each assignment.
    🔗
    🔗

    Essential Knowledge 1.6.16. 1.6.B.6.

    Assignment statements are often used to update information an app remembers about the user or the program’s state, such as a score or setting, so the app responds appropriately as the user interacts with it.
    🔗
    🔗
    🔗

    Subsection 1.6.4 Strings

    Essential Knowledge 1.6.17. 1.6.C.1.

    A string is an ordered sequence of characters used to represent text in a program.
    🔗
    🔗

    Essential Knowledge 1.6.18. 1.6.C.2.

    Apps often use strings to store and display user-facing information, such as names, messages, labels, or search terms.
    🔗
    🔗

    Essential Knowledge 1.6.19. 1.6.C.3.

    To initialize a string variable, programmers assign it an initial text value or an empty string before it is used so the program starts with a known value. An empty string has zero characters (""). It is not the same as a string that contains spaces (" ").
    🔗
    🔗

    Essential Knowledge 1.6.20. 1.6.C.4.

    String concatenation joins two or more strings to create a new string, such as combining a greeting with a user’s name.
    🔗
    🔗

    Essential Knowledge 1.6.21. 1.6.C.5.

    A substring is part of an existing string. Programs can create substrings to extract or use part of a text value, such as extracting the month from a date, reading a portion of a message, or checking for a word within a string.
    🔗
    🔗

    Essential Knowledge 1.6.22. 1.6.C.6.

    The output of code that uses string operations can be determined by tracing statements in order and keeping track of how string values change and what text is displayed.
    🔗
    🔗

    Essential Knowledge 1.6.23. 1.6.C.7.

    To communicate clearly with users, programmers use strings to store and generate text that apps display, such as prompts, feedback messages, and personalized responses.
