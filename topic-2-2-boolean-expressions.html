    Section 2.2 Boolean Expressions

    45 minutes
    Quick Links: 2.2.1, 2.2.2, 2.2.3, 2.2.4, 2.2.5, 2.2.6, 2.2.7
    🔗
    Apps are a lot more fun if they can respond to different user actions and decisions. For example, if you are playing a game, the app can check whether you have enough points to move to the next level. A social media app needs to ask you for your password and check that it is correct before allowing you to post a comment. Apps use Boolean expressions to make decisions based on true or false conditions, like in the flowchart below. In this lesson, you will learn how to use Boolean expressions in your code to change an app’s behavior.
    🔗

    Subsection 2.2.1 Boolean Expressions and Decision Making

    Essential Knowledge 2.2.1. 2.2.A.1.

    Apps often check conditions that have only two outcomes, such as whether a user is logged in, whether a checkbox is selected, or whether a password is correct.
    🔗
    🔗

    Essential Knowledge 2.2.2. 2.2.A.2.

    Programs make decisions by evaluating conditions that result in a Boolean value. A Boolean value has two possible values: true or false.
    🔗
    🔗
    In Python, Boolean values are represented by the keywords True and False.

    Essential Knowledge 2.2.3. 2.2.A.3.

    Apps can use Boolean expressions to decide what happens next, such as showing a message, allowing access, or changing what a user sees. A Boolean expression is an expression that evaluates to either true or false.
    🔗
    🔗

    Essential Knowledge 2.2.4. 2.2.A.4.

    Many Boolean expressions use comparisons, such as checking whether a score is high enough or whether an input meets a requirement like password length.

    Subsection 2.2.2 Relational Operators

    Essential Knowledge 2.2.5. 2.2.B.1.

    Apps and programs often compare values to enforce rules, personalize experiences, and prevent mistakes. Relational operators allow programs to evaluate questions such as whether a value is too low or whether one value matches another.
    🔗
    🔗
    Relational operators are operators like less than (<), greater than (>), and equal to (==) that compare two values or expressions. They are often used to compare a variable against a constant value or another variable or an expression. For example, the following Boolean expressions (which evaluate to true or false) can be used to see whether a number is positive or negative by seeing if it is greater than 0 or less than 0:
    🔗
    # Test if a number is positive (greater than 0)
number > 0
# Test if a number is negative (less than 0)
number < 0

    Essential Knowledge 2.2.6. 2.2.B.2.

    Relational operators compare two values and produce a Boolean result.
    🔗
    • Equals (==): The expression a == b evaluates to true when the values of a and b are equal, and evaluates to false otherwise.
      🔗
    • Greater than (>): The expression a > b evaluates to true when the value of a is greater than the value of b, and evaluates to false otherwise.
      🔗
    • Less than (<): The expression a < b evaluates to true when the value of a is less than the value of b, and evaluates to false otherwise.
      🔗
    • Greater than or equal to (>=): The expression a >= b evaluates to true when the value of a is greater than or equal to the value of b, and evaluates to false otherwise.
      🔗
    • Less than or equal to (<=): The expression a <= b evaluates to true when the value of a is less than or equal to the value of b, and evaluates to false otherwise.
      🔗
    🔗
    The relational operators == and != (not equal) can be used to compare values for equality. They return True or False boolean values. In Python, they can be used to compare numbers, strings, and other data types. For string comparisons like "hello" != "Hello", Python will check that each character is the same (including its case) in the two strings. Don’t confuse = and ==. One = sign changes the value of a variable. Two == equal signs are used to test if a variable holds a certain value, without changing its value!
    🔗
    The relational operators < and > can be used to compare values and determine whether one is less than or greater than the other. If you have trouble telling < and > apart, remember that less than sign (<) looks more like an L and always starts with the small pointy-end. To remember the correct order of the two characters in <= and >=, just write them in the same order you would say them in English: “less than or equal to” not “equal to or less than”.

    Subsection 2.2.3 Logical Operators

    Logical operators like and, or, and not are used to combine Boolean expressions. For example, the following Boolean expression (which evaluates to true or false) can be used to see whether a number is between 1 and 10:
    🔗
    # Test if a number is between 1 and 10
number > 1 and number < 10

    Essential Knowledge 2.2.8. 2.2.C.1.

    Apps and programs often combine multiple conditions to make decisions that feel predictable and personalized. Logical operators allow programs to answer questions such as whether all conditions are true, whether at least one condition is true, or whether a condition is not true. Logical operators can also support user-centered rules, such as allowing an action only when multiple conditions are met, like when all required fields are complete and the user agrees to terms.
    🔗
    🔗

    🔗

    Essential Knowledge 2.2.9. 2.2.C.2.

    Logical operators combine or modify Boolean values and produce a Boolean result.
    🔗
    • The expression condition1 and condition2 evaluates to true when both conditions are true, and evaluates to false otherwise.
      🔗
    • The expression condition1 or condition2 evaluates to true when at least one condition is true, and evaluates to false when both conditions are false.
      🔗
    • The expression not condition evaluates to true when the condition is false, and evaluates to false when the condition is true.
      🔗
    🔗
    The operator and is used to combine two things and verify that BOTH are true. The operator or is used to verify that at least one is true. The operator not is used to see if something is not true. With numerical values, the and operator is often used to see if a number is in an range, for example to get a B grade, your grade must be between 80 and 90 (not including 90).

    In English, we often use an exclusive-or like in the sentence “do you want to be player 1 or player 2?” where you can’t be both player 1 and player 2.     Essential Knowledge 2.2.10. 2.2.C.3.

    The result of a logical expression can be determined by evaluating each condition and then applying not, and, and or to determine whether the overall expression is true or false. Logical expressions can include multiple conditions. Parentheses can be used to group conditions and make the intended order of evaluation clear when combining not, and, and or.
